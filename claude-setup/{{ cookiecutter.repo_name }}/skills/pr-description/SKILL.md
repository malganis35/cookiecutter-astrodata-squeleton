---
name: pr-description
description: Rédige des descriptions de pull request. À utiliser lors   de la création ou de la rédaction d'une PR, ou d'un résumé de changements.
---

Pour rédiger une description de PR :
1. Lancez git diff main...HEAD pour voir tous les changements
2. Rédigez une description selon ce format :

## What
Une phrase expliquant ce que fait cette PR.

## Why
Contexte bref sur la raison de ce changement

## Changes
- Points listant les changements précis effectués
- Mentionnez les fichiers supprimés ou renommés
